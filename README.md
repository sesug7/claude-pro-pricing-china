## Pro 到底给什么

官方帮助中心给 Pro 列了五项权益：比 Free 更高的单次会话用量；高峰期优先访问 Claude；新功能早期体验；Claude Code 使用权限；支持更长的多步任务。官方定价页的功能表里，Claude Code 这一行在 Pro 列同样是 Yes。

最常见的误解是把 Pro 当成“聊天 + API 打包”。Pro 是聊天产品的订阅，Claude Console 的 API 用量要单独开通、单独付费，两者账单互不相干。你要把 Claude 接进自己的产品里，Pro 一分钱都不抵扣。

另一个误解是“买了 Pro 就能无限用”。官方明确写了 Pro 有额度限制，还保留另设周/月上限、限制模型与功能使用的权利，原话是 “We don't guarantee uninterrupted service”。

## 额度怎么算：五小时和每周两道限制

Pro 同时受两道限制约束：一个是五小时窗口，一个是每周上限。每周上限跨所有模型生效，重置时间在账号上是固定的，和你什么时候开始用、订阅从哪天算起都无关，每个周期发放完整的一份周额度。下次重置时间在 Settings > Usage 里看。

能发多少条消息没有标准答案。官方说明消耗取决于消息长度、附件长度、当前对话长度、所用模型或功能，具体条数从不公布。所以“Pro 一天能聊多少轮”这类问题，任何给出确切数字的说法都不可靠。

额度用完之后有两条路。等提示里的重置时间，或者打开 usage credits，超出部分按标准 API 价计费，可以设每月上限，费用与订阅费分开出账。另外还有一个多数教程没提的机制：limit resets，能把五小时额度或每周额度直接重置回满。

电脑、手机、桌面端、Claude Code 共用同一份额度。白天在网页上聊得多，晚上 Claude Code 就更容易撞顶。

## 各档位怎么选：三条判断规则

**Pro 一周内多次撞到周上限 → 考虑 Max 5x。** 判断依据是撞顶频率，不是“感觉用得挺多”。偶尔一次撞顶，新建会话、减少附件、关掉不需要的工具就能省下不少额度。

**升到 Max 5x 后仍然经常撞顶 → 再考虑 Max 20x。** 5x 和 20x 之间差了四倍用量和 $100 月费，只有长时间跑 agent、多个项目并行这类场景才用得上。

**团队 2 人以上 → 先算 Team 席位价。** 标准席位年付 $20/人/月，两个人一年就是 $480，比两份个人 Pro（$480）持平，但多了协作空间和团队共享 API credits。这条合规路径在代充类文章里几乎没人提。

官方渠道从低档升到高档，按剩余账期比例补差价，升级后新额度立即生效。年付 Pro 升 Max 时，剩余年费超出 Max 价格的部分会转成账户余额。通过第三方渠道开通的 Pro，部分渠道在周期内无法直接升 Max，要等到期变回免费版再下单，各渠道规则不同，下单前问清楚。

## 第三方代充：报价区间和它的前置条件

已经核验到的第三方月付报价，人民币大致在 130 多元到 260 多元之间，多数落在 150–190 元，同一档位不同渠道能差出七八十元。这是第三方渠道报价，不是官方价格，也不能拿来和 $20 直接换算比较。

代充普遍有前置条件：账号当前必须是免费版、没有生效中的订阅，且已经通过 Anthropic 的身份验证，注册地区、手机号归属地与日常登录地区保持一致。不满足这些条件，多数渠道会直接告诉你开不通。开通失败通常全额退款，开通后账号被 Anthropic 限制则一般不在退款范围内，这条差异在下单前必须问明白。

成品号和合租是另外两条路。成品号的账号归属不完全在你手里；合租拿到的不是原生个人账号，而是共享额度或平台封装的访问方式，Claude Code 的支持程度也各不相同。要保留历史对话和项目上下文，代充到自己的账号上更稳。

## 用 Claude Code 的人要额外注意四件事

**额度是共用的。** VS Code、Cursor、JetBrains 里的插件都算在同一份额度里。

**随时看用量。** 网页在 Settings > Usage，Claude Code 里输入 `/status`。

**`ANTHROPIC_API_KEY` 会绕开订阅。** 环境变量里存在这个 key 时，Claude Code 优先走 API 计费，不消耗订阅额度，表现就是“明明有 Pro 却提示余额不足”。处理办法是 `unset ANTHROPIC_API_KEY`，把 shell 配置里的 export 行删掉，重开终端后 `/status` 确认。

**Max 附带的 API credits 用不到 Claude Code 上。** 官方写明这部分额度只能在 Console 用，不能在 Claude Code 和 Claude App 里用。
